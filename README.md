📌 نظرة عامة

Market هو نظام محاسبي ورقابي متخصص في إدارة مشتريات وتوزيع الخضروات والفواكه في أسواق الجملة، مبني ليغطي دورة العمل اليومية الكاملة لمؤسسة توريد: من تسجيل طلبات البقالات في وردية الليل، إلى توليد جدول فرز الصباح، تسليم البضاعة للبقالات، تسجيل سندات القبض والصرف، ومتابعة أرصدة العملاء والموردين، وصولاً إلى التقارير المالية والرقابية وسجل التدقيق الكامل.

النظام مبني بعناية لتناسب بيئة العمل الميداني في اليمن (توقيت صنعاء/الرياض UTC+3، أرقام هاتف +967، عملة ريال سعودي)، مع دعم كامل للغة العربية وواجهة RTL وتحسين كامل لشاشات الجوال.

✨ أبرز المميزات

🗓️ دورة العمل اليومية الكاملة
- كشف يومية ذكي: يُنشأ تلقائياً لكل يوم سوق، ويرحّل تلقائياً عند بدء وردية الليل (6:00 مساءً) لتجهيز مشتريات اليوم التالي.
- شاشة إدخال ميدانية للعامل: مصفوفة كميات (أصناف × بقالات) مع أسعار شراء وبيع وحساب تلقائي للأرباح.
- حفظ طلبات الليل: قفل طلبيات نهاية اليوم تمهيداً للشراء الصباحي.
- جدول فرز الصباح: توليد تلقائي لجدول فرز وتسليم لكل بقالة على حدة، مع تتبع الكمية المسلّمة والتأكيد.

💰 المحاسبة والأرصدة
- سندات قبض وصرف برقم تسلسلي وطرق دفع متعددة (نقدي / تحويل / شيك) ورقم مرجعي.
- أرصدة تراكمية: رصيد البقالة (مدين) ورصيد المورد (دائن) يُحدَّثان تلقائياً مع كل فاتورة وسند.
- حدود ائتمانية لكل بقالة مع مؤشر نسبة استهلاك الائتمان.
- كشف حساب تفصيلي لأي طرف (مدين / دائن / رصيد تراكمي).

👥 الأدوار والصلاحيات
- مدير النظام (Admin): لوحة تحكم مالية، تقارير، إعدادات، إدارة المستخدمين والصلاحيات.
- عامل ميداني (Worker): شاشة إدخال الكميات فقط، مع صلاحيات قابلة للضبط (إضافة مورد/صنف، تعديل أسعار، رؤية تكلفة الشراء، قفل الكشف بعد الحفظ).
- بوابة البقالة (Grocery Portal): دخول برقم PIN خاص بكل بقالة، بصلاحية قراءة فقط لمتابعة استلامات الصباح وكشف الحساب.

🖨️ الطباعة والتقارير
- قوالب طباعة احترافية قابلة للتبديل: Royal Classic و Modern Minimal.
- طباعة/حفظ PDF: فاتورة اليومية، كشف الحساب، جدول فرز الصباح، السندات المالية.
- تعديل شامل لليوم: من شاشة التقارير يستطيع المدير فتح أي يوم سابق وتعديله بالكامل.
- سجل تدقيق (Audit Log): توثيق آلي لكل عملية حساسة (آخر 300 حركة) مع القيم القديمة والجديدة.

🎨 تجربة الاستخدام
- 5 ثيمات فاخرة: Royal Navy، Indigo Gold، Emerald Botanical، Dark Luxury، Ruby Luxury.
- تصميم عربي RTL بالكامل بخطوط Cairo وTajawal.
- تفاعلات حركية (Motion)، أيقونات Lucide، وتأثيرات احتفالية (Canvas Confetti).
- تحسين كامل للجوال (Mobile-First) مع جلسات دخول تدوم على الجهاز.

🚀 التثبيت والتشغيل

المتطلبات
- [Bun](https://bun.sh) (موصى به) أو Node.js 22+

خطوات التشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/yunis-alafeef/Market.git
cd Market

# 2. تثبيت الاعتماديات
bun install        # أو: npm install

# 3. (اختياري) إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل: VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY

# 4. التشغيل في وضع التطوير (المنفذ 3000)
bun run dev

# 5. بناء النسخة الإنتاجية
bun run build

# 6. معاينة نسخة الإنتاج
bun run preview
```

سكربتات npm المتاحة

السكربت	الوظيفة	
`dev`	تشغيل خادم التطوير على المنفذ 3000 مع دعم الشبكة	
`build`	بناء نسخة الإنتاج إلى مجلد `dist`	
`preview`	معاينة نسخة الإنتاج محلياً	
`lint`	فحص أنواع TypeScript دون تصريف	
`clean`	حذف مخرجات البناء

💾 التخزين والنسخ الاحتياطي

- التخزين المحلي (localStorage): جميع البيانات تُحفظ فورياً على الجهاز بعد كل عملية، ويتحمل النظام إنشاء كشف يومية جديد تلقائياً عند بدء يوم السوق الجديد.
- التهيئة الذكية: أول تشغيل يولّد بيانات أساس (5 بقالات، 4 موردين، 10 أصناف خضروات) جاهزة للعمل الفعلي.
- جاهزية Supabase: بنية الربط السحابي موجودة عبر `@supabase/supabase-js` ومتغيرات البيئة، لتفعيل المزامنة متعددة الأجهزة عند الحاجة.
- زر إعادة تعيين البيانات متاح في شاشة الإعدادات للمدير (بعد تأكيد يدوي).
